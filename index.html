Priča o Type R

Type R program Honda je pokrenula 1992. godine s ciljem stvaranja automobila koji donosi iskustvo trkaćih staza na javne ceste — bez kompromisa. Filozofija je jednostavna: minimalni balast, maksimalni fokon.

Svaki Type R prolazi kroz poseban proces kalibracije u Honda R&D centru u Tochigi. Svaki motor ručno sklapa jedan mehaničar — i potpisuje ga. To nije marketing — to je obećanje.

Civic Type R linija počela je 1997. s EK9 — isključivo JDM modelom koji je postavio standarde za cijelu klasu. Danas, FL5 nastavlja tu tradiciju kao najmoćniji Civic ikad napravljen.
